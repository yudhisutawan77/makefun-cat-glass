The one sentence a house cat would say in its own defence, five seconds
after sweeping a glass off the table — no apology, no confession, just the
most convincing case a cat can make for itself:

> That glass squatted rent-free in my sunbeam, blocking my bird TV — the floor is where freeloaders live now.

One sentence, 107 characters. The entry program (`main.py`, standard
library only) writes exactly that sentence to `/output/entry.txt`.
